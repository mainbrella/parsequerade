Getting started

Parsequerade

A proposed JSON REST facade for reading App Store Connect data through explicit resources, predictable pagination, and connection-scoped access.

Clients call ordinary routes such as /apps and receive flat JSON objects. The service would own Apple authentication, translate Apple’s resource envelopes, and resolve nested resources such as a version localization by its exact locale.

Proposed The facade is a design plan; no service or authenticated API is available yet. Routes and examples describe the planned contract.

Common reads

List appsGET /appsFind an app by bundle ID, name, or SKU. List app informationGET /apps/{appId}/app-infosRead app-level information and category IDs. List versionsGET /apps/{appId}/versionsSelect a platform and version state explicitly. List buildsGET /apps/{appId}/buildsInspect processed builds for an app. Read a version localizationGET /apps/{appId}/versions/{versionId}/localizations/{locale}Address a specific locale without fallback.
