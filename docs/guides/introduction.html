Getting started

Introduction

Read App Store Connect data through explicit resources, predictable pagination, and connection-scoped access.

Clients call ordinary routes such as /apps and receive flat JSON objects. The service would own Apple authentication, translate Apple’s resource envelopes, and resolve nested resources such as a version localization by its exact locale.

Read-only implementation The Worker implements 12 core read routes for apps, app information, versions, localizations, age ratings, and review contacts. Configure your Apple connection and facade key, then deploy it in your Cloudflare account. Writes, reports, builds, and copy workflows remain planned. The reference labels each route’s implementation status.

Common reads

List appsGET /appsFind an app by bundle ID, name, or SKU. List app informationGET /apps/{appId}/app-infosRead app-level information and category IDs. List versionsGET /apps/{appId}/versionsSelect a platform and version state explicitly. Read a version localizationGET /apps/{appId}/versions/{versionId}/localizations/{locale}Address a specific locale without fallback.
