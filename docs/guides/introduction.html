Getting started

Introduction

Read App Store Connect data through explicit resources, predictable pagination, and connection-scoped access.

Clients call ordinary routes such as /apps and receive flat JSON objects. The service owns Apple authentication, translates Apple’s resource envelopes, and resolves nested resources such as a version localization by its exact locale.

Core implementation The Worker implements 12 core read routes and hosted connection setup/revocation. Connect an Apple team key to receive a read-only facade key, or use the operator configuration path for your own deployment. The scoped age-rating POST is also implemented; request read and write capabilities when connecting. Other writes, reports, builds, and copy workflows remain planned; the reference labels each route’s implementation status.

Common reads

List appsGET /appsFind an app by bundle ID, name, or SKU. List app informationGET /apps/{appId}/app-infosRead app-level information and category IDs. List versionsGET /apps/{appId}/versionsSelect a platform and version state explicitly. Read a version localizationGET /apps/{appId}/versions/{versionId}/localizations/{locale}Address a specific locale without fallback.
